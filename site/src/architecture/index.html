THE COMPOSITION

Small contracts. Explicit connections.

FOUNDATIONS

Types, authority, filesystem contracts

harw-types, harw-authority, and harw-fsutil carry the identities, permission algebra, and file boundaries used above them.

CAPABILITIES

Context, tools, plans, and state

Separate contracts define what can be executed, what can be remembered, and how a unit of work is admitted.

ORCHESTRATION

Core sessions and runtime assembly

harw-core owns the turn loop; bridges connect child agents and durable plans. harw-runtime composes services under the selected entry profile.

CONSUMERS

CLI, TUI, SDK, and restricted transports

The CLI composes the application. TUI, web, jobs, and gateways each use their own profile rather than inheriting a universal tool surface.
