# OpenAI lifecycle audit — 2026-10-14

Official source: https://developers.openai.com/api/docs/deprecations

OpenAI announced on October 1, 2026 that gpt-5.3-codex, gpt-5.4-nano, and gpt-5.1 will be retired on April 1, 2027. Official replacements: gpt-6-sol, gpt-6-luna, gpt-6-sol respectively.

The current model catalog also features gpt-6-astra, gpt-6.1-sol and gpt-6-luna. See https://developers.openai.com/api/docs/models and https://developers.openai.com/api/docs/pricing.

This is research only, not an implemented runtime change.
