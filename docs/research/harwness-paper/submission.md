## Record description

Harwness is a Rust-based agent runtime that separates model proposals from trusted identity, authority, admission, execution and durable state. This architecture and implementation report examines the author's software artifact at a pinned repository revision. It covers compiled agent definitions, authority attenuation, persistent work coordination, uncertain-effect reconciliation, Linux enforcement reporting and the optional Detect-Orient-Defend host-security plane. A source-evidence map identifies the implementation paths and qualifications behind the claims. The report also provides a falsifiable evaluation protocol for authority composition, prompt-injection containment, crash recovery, isolation, observation and useful task completion.

This is an unreviewed technical preprint. It distinguishes source-observed mechanisms, limited integrations, attributed local validation reports and prospective experiments. It presents no new empirical benchmark dataset and makes no comparative performance or universal security claim. The accompanying files include the PDF, editable sources, bibliography, evidence metadata and a deliberately unpopulated evaluation template.

**AI assistance disclosure:** ChatGPT (OpenAI) assisted with repository inspection, literature checking, manuscript revision and document preparation. The research artifact is Harwness's software design and implementation. Responsibility for the deposited work remains with the author; AI tools are not listed as authors or contributors.
