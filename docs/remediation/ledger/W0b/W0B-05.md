## Verträge – umgesetzt

### §principal (`harw-types/src/principal.rs`)
- `PermissionTier`: identische Varianten/Doku, Derives `Clone, Copy, Debug,
  PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize`,
  `#[serde(rename_all = "snake_case")]`.
- `PrincipalKind`, `IngressSurface`: `Clone, Copy, Debug, PartialEq, Eq, Hash,
  Serialize, Deserialize` (snake_case). `Principal`: `Clone, Debug, PartialEq,
  Eq, Serialize` – **kein** Deserialize; Felder privat.
- `child_of(role)`: kind `Model`, surface `Child`, tier `min(parent, Operator)`,
  id `"<parent-id>/<role>"` (Entscheidung dieses Agenten, Vertrag lässt die id offen).
- `approval_actor()` – Abbildung auf `ApprovalActor::Operator` (einzige
  passende Variante; `ChannelPeer` braucht ChannelId+PeerId, die ein Principal
  nicht trägt):
  - Human+Tui → `Operator { id: "local-tui" }`
  - Human+Cli → `Operator { id: "local-cli" }`
  - Human+Web → `Operator { id: "owner" }`
  - Channel+Mcp → `Operator { id: principal.id }`
  - sonst `None` (auch alle Kind-Principals).

### §runtime-spec (`harw-runtime/src/spec.rs`, `error.rs`)
- Alle Typen laut Vertrag; Enums `Clone, Copy, Debug, PartialEq, Eq, Hash`;
  `EntryProfile`, `RuntimeSpec`, `RightsSnapshot`: `Clone, Debug, PartialEq, Eq`;
  `RootBudget`: zusätzlich `Copy`.
- `EntryKind::profile()` exakt nach Tabelle. Konkretisierungen: `Web` → `{ReadWorkspace}`
  (Spec-Wert; tier-abhängig erst W2B-02 `permissions_for_tier`),
  `JobPlanNode` → `{ReadWorkspace, WriteWorkspace}` (Obergrenze),
  `Doctor` → Rechte/Registry/Ops wie Tui, Ask `Fail`, Spawner `None`.
  Kein Eintrag vergibt `NetworkAccess`/`ReadSecrets`/`ManagePlugins`/`ReadCargoRegistry`.
- `RuntimeError { Config, Trust, Discovery, Registry, Sandbox, Provider, Store, Spawner }`
  via `#[derive(Debug, HarwError)]`; jede Variante trägt `{ detail: String }`
  (Vertrag nennt nur Variantennamen). Alias `RuntimeResult<T>` wird vom Makro
  erzeugt und aus `lib.rs` re-exportiert.
