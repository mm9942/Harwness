## Prüfreihenfolge

Prompt-Job (W1-13 unverändert, danach neu): Scope → Prompt → Budget/Wanduhr → **runtime_root** (`None` ⇒
`Blocked{"job runtime requires a HARW home"}`) → Ledger/BudgetedModelProvider → Montage (`JobEntry::Prompt`,
`job_principal(submitter operator id)`, session `durable-job-<id>`, TranscriptStateStore, keine Verengung) →
`new_root_session(id, tx, ttx, None)` → Turn in `timeout(wall)` mit `assembly.model()` (= budgetierter Provider) und
`state_store`. Montage-/Session-Fehler ⇒ `Failed{"could not assemble the job runtime: …"|"could not create the job root session: …"}` (jeweils `sanitize_failure`), kein Modellaufruf.

Plan-Knoten: plan_services → Payload → node_kind (alles `Blocked` wie bisher) → `derive_plan_node_sandbox` (bleibt
Prüfung; Fehler ⇒ `fail_plan_node`) → runtime_root (`None` ⇒ `report_plan_node_outcome(Blocked{…})`, Knoten wird
invalidiert) → `plan_node_narrowing` = `RuntimeNarrowing{profile_for_node_kind(kind, may_write), plan_node_identity, derived.permissions()}`,
`JobEntry::PlanNode{kind, may_write}` → Montage mit cwd = `derived.workspace().canonical_root()`,
`job_principal(services.actor())` → Fehler ⇒ `fail_plan_node` → Turn (`PauseDisposition::Failed`) → `report_plan_node_outcome`.

Die `RuntimeAssembly` ist lokal in `assemble_job_turn` (synchron) und wird vor jedem `await` gedroppt; die Sitzung
besitzt ihre Registry, das Modell wird als `Arc` herausgereicht. Kein `close_session` (Job-Einstiege haben keine
Contributors ⇒ keine Lifecycle-Hooks).

## Verhaltensänderungen (für CHANGELOG/Tracking)

1. E3: `harw serve` ohne Home ⇒ jeder ausgeführte Job (Prompt nach Scope/Prompt/Budget, Plan-Knoten nach Sandbox-Prüfung) endet `Blocked{"job runtime requires a HARW home"}`; Plan-Knoten werden dabei invalidiert. CHANGELOG-Eintrag nicht in J1-Ownership.
2. Montage je Job (Config-Load, Projekterkennung) — I/O pro Job; Config-/Trust-/Discovery-Fehler lassen Jobs `Failed` enden.
3. Prompt-Job-Session trägt jetzt den Runtime-SpawnContext: leere Sandbox (`JobPrompt`), Decke `Closed`, frischer Root-Trace, `organizational_role` aus `SpawnerPolicy::None`, Approval-Kette mit `ask:block-job`. Vorher: kein SpawnContext.
4. Plan-Knoten: Session-Sandbox ist `root_sandbox(JobPlanNode, discovered project_root).restrict(derived.permissions())` statt der abgeleiteten (an die geerbte Bindung gebundenen) Sandbox; die abgeleitete Sandbox bleibt Prüfung und Rechtequelle. Projektwurzel folgt `discover_project(canonical_root)` — kann über dem Workspace liegen, wenn dort Marker fehlen (offen für Review).
5. Plan-Knoten: Trace ist jetzt ein frischer Runtime-Root-Trace (vorher bewusst `None`, AW1-01c). Die AW1-01c-Lücke (`JobClaim` ohne `trace`) bleibt offen; Vererbung bräuchte eine Assembly-Option (W4a/R-Folgeauftrag).
6. Decke Plan-Knoten `LocalRoot` jetzt aus Profil statt `root_context`; Prompt-Job `Closed`.
7. Assembly-Fehlergrund einheitlich `"could not assemble the job runtime: …"` (vorher Plan-Knoten `"could not assemble the plan-node tool registry: …"`).
8. Session-Ereignisse/Turn-Ereignisse werden verworfen (wie vorher `_event_rx`).
